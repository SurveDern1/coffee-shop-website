# Coffee 26 — версия 3

Полностью переработанный сайт по новым референсам. На первом плане — изображения, категории и вращающееся меню, а не текстовый прайс-лист.

## Открыть

```sh
python3 -m http.server 4173
```

Затем http://localhost:4173. Для проекта нужен HTTP-сервер (ES modules). Вместе с архивом предоставляется автономный `coffee-26-v3-preview.html`: он открывается напрямую, без установки и интернета.

## Структура и сценарий

- Главная: крупный баннер Coffee 26, лента категорий, десять карточек-категорий с изображениями, кофейные карточки и настоящее колесо завтраков.
- Каждая категория открывается отдельным экраном: `#/menu/breakfast`, `#/menu/coffee` и т.д. Прямой выбор позиции: `#/menu/coffee/cappuccino`.
- На каждом экране — колесо и полный каталог изображений всех позиций категории. У каждого блюда и напитка собственное локальное изображение: 53 файла в `assets/menu/`.
- Поиск по всем названиям и ингредиентам, результаты с картинками, пустое состояние, возврат к поиску.
- Все размеры, цены, ингредиенты, шесть дополнений к завтракам и альтернативное молоко сохранены из PDF. Исходный PDF и версия без JavaScript включены.

## Настоящее вращение

Во время свайпа или перетаскивания изображения непрерывно движутся по круговой дуге и поворачиваются. После отпускания колесо доворачивается и фиксирует выбранную позицию; название, порция, состав и цена меняются вместе с ней. Работает во ВСЕХ десяти категориях, включая сэндвичи, чай, коктейли и вино. Есть стрелки, клавиатура и прямой выбор по карточке. Вертикальный скролл не перехватывается. В reduced-motion режиме анимация отключена.

## Файлы

- `menu.js` — данные исходного меню, нормализация и поиск.
- `app.js` — маршруты, страницы, поиск и класс `MenuWheel`.
- `style.css` — новый дизайн и адаптивность.
- `assets/menu/*.webp` — 53 новые индивидуальные фотографические иллюстрации 1024×1024 с прозрачностью. Каждый объект создан отдельно, а не вырезан из маленького коллажа. Маски по реальному контуру предметов, сглаженные края, отдельная сегментация стекла с удалением теней и нейтрализацией зелёного фона.
- `assets/hero-v2.webp` — баннер.
- `assets/menu/provenance.json`, `assets/SOURCES.md` — происхождение изображений.
- `menu.html` — полное текстовое меню; обновление: `node scripts/build-text-menu.mjs`.
- `npm test` — тесты полноты меню, чувствительных цен, поиска и всех 53 изображений.
- `QA.md` — выполненные проверки и ограничения.

## Impeccable

Impeccable 4.8.0 установлен в `.agents/skills/impeccable/`: официальный навык, справочники и launcher, с сохранёнными лицензией и notice. Контекст, принципы визуальной иерархии, анимации, доступности и проверки использовались при переработке. `PRODUCT.md` фиксирует требования; `DESIGN.md` описывает реализованную версию. Для установки в другом совместимом редакторе: `npx impeccable@4.8.0 install`.

## Важные уточнения

Все изображения новой версии — специально подготовленные иллюстрации, не реальные фотографии Coffee 26. Об этом сказано в интерфейсе. Точная подача и некоторые детали могут отличаться; составы и цены берутся из текста меню, а не изображения. Замените иллюстрации реальными фото для документальной точности. Скрипт подготовки в `scripts/` содержит пути исходной рабочей сессии и требует Python, Pillow, NumPy и OpenCV; посетителям сайта и для обычного запуска он не нужен.

Адрес, контакты и общие часы работы не предоставлены, поэтому не придуманы. До 20:00 — только завтраки. Валюта обозначена `р.` как в PDF, без неподтверждённого кода. Для трёх видов молока в PDF есть только два значения доплаты `1,2 / 3,5`: сайт сохраняет неоднозначность, а не назначает цены наугад. Онлайн-заказа, корзины и фиктивных форм нет.

## GitHub Pages

Загрузите содержимое папки в `SurveDern1/coffee-shop-website`, ветка `main`, включая `assets/`, `.nojekyll` и скрытую `.agents/`. Затем **Settings → Pages → Deploy from a branch → main → / (root)**. GitHub покажет действующий адрес после завершения публикации. Hash-маршруты не требуют серверной настройки или редиректов.

В этой сессии загрузка в GitHub не выполнена: ранее подключение вернуло 403 при записи в новый репозиторий. Локальные файлы и архив готовы независимо от GitHub.
